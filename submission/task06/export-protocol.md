# 第 6 题｜固定导出与验收口径（导出前写定）

## 1. 权重来源、模型格式、类别映射、输入尺寸、置信度阈值
- 权重来源：预训练 yolo11n.pt（仓库根目录，SHA-256 0ebbc80d4a7680d14987a577cd21342b65ecfd94632bd9a8da63ae6417644ee1）
- 模型格式：ONNX，固定输入、dynamic=False
- 类别映射：sports ball（COCO 类别 32），PyTorch 与 ONNX 使用同一映射
- 输入尺寸：416 x 416（正方形，letterbox + 补边）
- 置信度阈值：0.10
- 匹配门槛：IoU >= 0.50（本题切换判据为配对框 IoU >= 0.95）

## 2. 同一批测试图片与必查情况
- rt-100.jpg：球完整可见，必须能检出并配对
- rt-150.jpg：球出画（贴上边缘），必须核对两边空结果是否一致
- rt-200.jpg：无球帧，两边都应为空结果

## 3. 需要保存的内容
- 框坐标（统一换算回原图像素坐标的 xyxy）、类别名、置信度、空结果
- 原始日志：export.log（导出过程）、backend-comparison.json（逐图对照）

## 4. 计时口径（本题不测，留作选做板卡项）
- 预热 5 次、重复 20 次；分别记录预处理、模型推理、结果整理三段耗时
- 计时范围只含单帧推理链路，不含模型加载

# 第 5 题｜独立测试协议（先固定，后看结果）

- 权重：预训练 yolo11n.pt（不是第 4 题的微调权重）
- 设备：cpu
- 输入尺寸：416
- 置信度阈值：0.10
- 类别：sports ball（预训练 COCO 类别，由 lab.py 自动选取）
- 匹配门槛：IoU >= 0.50
- 数据：annotations.csv 中 split=test 的 8 张 Jackson 罚球图（7 有球 + 1 无球；jackson-059 为无球帧）
- 统计写法：匹配帧数 / 有球帧数；误报帧数 / 无球帧数；多余框单列

## 判据（在看到任何结果之前写定）
- 正确匹配：有球帧，最高 IoU >= 0.50
- 有球漏检：有球帧，无检测或最高 IoU < 0.50
- 无球误报：无球帧，检测数 >= 1
- 多余框：有球帧中除最高分框之外仍存在的检测框数量

## 预先声明（事后对照用，不作为结论）
- 416 输入会把球缩得更小，预期漏检率高于第 3 题 A 组（640/0.10 时为 4/12）
- 若出现低分框，需核对它是否只是把阈值放低所致
